# 🎮 Elementa (Prototype)

Selamat datang di **Elementa**, sebuah prototype game berbasis web yang dikembangkan menggunakan [Next.js](https://nextjs.org/). Proyek ini dibuat sebagai tugas dan portofolio untuk Ujian Tengah Semester (UTS) mata kuliah Pengembangan Game.

## 🌍 Tentang Game
Elementa mengajak pemain untuk menjelajahi berbagai wilayah unik, mulai dari *Reruntuhan Kuno*, *Hutan Tercemar*, *Lembah Angin*, hingga *Gunung Berapi*. Setiap stage dirancang dengan rintangan khusus, efek suara interaktif (SFX), dan musik latar (BGM) yang membangun atmosfer petualangan.

## ✨ Fitur Utama
- **Eksplorasi Peta Interaktif:** Navigasi peta untuk memilih berbagai pulau dan wilayah.
- **5 Stage Menantang:** Desain lingkungan yang beragam dengan tingkat kesulitan yang terus meningkat hingga *Boss Fight*.
- **Audio Imersif:** Dilengkapi dengan puluhan efek suara aksi (tembakan laser, meriam, sihir, ledakan) dan BGM khusus untuk setiap stage.
- **Modern Tech Stack:** Dibangun menggunakan Next.js (React) dan TypeScript untuk performa yang optimal.

## 🚀 Cara Menjalankan Game Secara Lokal

Pastikan Node.js sudah terinstal di perangkatmu. Kemudian, jalankan perintah berikut di terminal:

```bash
# 1. Install dependencies (jika belum)
npm install

# 2. Jalankan development server
npm run dev
